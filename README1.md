# 커리어 브릿지 수정 작업 정리

같은 폴더의 `middle-career-platform.zip`에 수정된 전체 프로젝트가 들어 있습니다.
압축을 풀면 안에 설치·배포 명령어를 정리한 `README.md`가 따로 있습니다.

> **아직 빌드·실행 확인을 하지 않았습니다.** 작업한 PC에 Node.js가 없었기 때문입니다.
> 처음 빌드할 때 오타나 타입 오류가 나올 수 있습니다. 오류가 나면 메시지를 그대로 전달해 주세요.

---

## 1. 작업 배경

- GitHub(Letpang/middle-career-platform)의 코드는 6월 첫 업로드 버전이었습니다. 실제 사이트보다 훨씬 오래된 코드였습니다.
- 실제 사이트의 서버 코드(고용24 연동, 방문자 수, AI 질문창)는 GitHub에도, 이 PC에도 없었습니다.
- 그래서 공개된 사이트 화면 파일에서 기존 기능을 복원하고, 서버는 새로 작성했습니다.
- 그 위에 파주 중장년내일센터 모니터링 설문 8건과 **기관 교육과정 직접 등록 기능**을 반영했습니다.

## 2. 설문 의견 반영 내용

### 일자리
- 공고 카드에서 **근무지·급여·근무형태·경력/학력·마감일**이 바로 보입니다.
- 공고 제목에서 **교대·야간·격일·입주·자격증** 같은 조건을 읽어 표시로 붙입니다.
- **"상세 조건 펼치기"**를 누르면 근무시간·필요 자격·4대보험·복리후생을 사이트 안에서 바로 볼 수 있습니다. 공고를 한 번 더 눌러 들어가지 않아도 됩니다.
- 지역(고양·파주·김포)을 고른 상태에서도 **키워드 검색**이 됩니다.
- 추가한 필터:
  - 직종별 필터 (공고 수 표시)
  - 경력 무관
  - 학력 무관
  - 교대·야간 제외
  - 마감 임박 제외
- 고용24 오류(HTTP 502 등)가 나면 자동으로 다시 시도하고, 결과를 20분 동안 저장해 둡니다. 그래도 실패하면 "다시 시도"와 "고용24에서 직접 찾기" 버튼을 보여 줍니다.

### 채용행사
- 관내 채용행사 링크의 **서울 강서를 김포고용복지+센터로 교체**했습니다.
- **고용24 전국 채용행사(중장년 일자리박람회 포함)** 링크를 추가했습니다.
- 기관과 센터가 직접 등록한 행사는 **월별 달력**으로 보입니다. 날짜를 누르면 그날 행사가 나오고, 지역 필터도 있습니다.

### 다른 채용사이트
- 설문에서 지적된 곳에 **"회원가입 필요"** 표시를 달았습니다.
- 가입이 필요한 분야(요양·주택관리·경비)에는 "고용24 공고를 먼저 확인하라"는 안내를 넣었습니다.

### 교육
- **서영대 → 미래평생교육원, 두원공대 → 평생교육원** 주소로 고쳤습니다. 이전에는 대학 홈페이지로 연결되었습니다.
- **생애경력설계·재도약** 안내를 추가하고, 누르면 상담 신청으로 연결됩니다.
- 기관이 등록한 교육과정을 **지역·교육비(무료/국비/유료)·방식(대면/온라인/혼합)·분야**로 비교할 수 있습니다.
- 교육 카드의 **"수료 후 지원 가능한 일자리"**를 누르면 해당 채용공고 검색으로 바로 이동합니다.

### 상담지원
- **화상상담을 삭제**했습니다. 방문상담과 전화상담만 남았습니다.
- **전화상담은 프로필에 경력 사항을 작성해야 신청**할 수 있습니다. 신청하면 프로필 요약이 상담사에게 함께 전달됩니다.
- 상담 받을 센터(고양/파주)를 고르고, 개인정보 수집·이용 동의를 받습니다.
- **신청 내용이 이제 실제로 센터 관리자 화면에 접수됩니다.** 기존 사이트는 신청자 브라우저에만 저장되고 센터에는 전달되지 않았습니다.
- FAQ에 국민취업지원제도 참여자 안내를 추가했습니다.

### 프로필
- **이력서 파일 첨부**(한글·워드·PDF, 10MB 이하)를 추가했습니다.
- **희망 직종·희망 지역**을 넣으면 맞춤 일자리와 교육과정을 추천합니다.
- 프로필은 사용하는 기기에만 저장되고 서버로 가지 않습니다. 가명으로 입력해도 됩니다.
- 센터 공용 PC에서 쓸 수 있게 **"프로필 지우기"** 버튼을 넣었습니다.

## 3. 새 기능: 기관 교육과정 직접 등록

1. 교육기관 담당자가 **`/org`**(사이트 맨 아래 "교육기관 등록·로그인")에서 계정을 신청합니다.
2. 센터 담당자가 **`/admin`**(사이트 맨 아래 "센터 관리자")에서 관리자 비밀번호로 로그인해 **승인**합니다.
3. 승인된 기관은 **교육과정과 채용행사를 직접 등록·수정·숨김·삭제**할 수 있습니다.
4. 등록한 내용은 교육 페이지와 채용행사 달력에 바로 나타납니다.

### 관리자 화면(`/admin`)에서 하는 일
- 기관 계정 승인·반려·승인 취소 (사유 메모 가능)
- 상담 신청 확인: 센터별 목록, 프로필 요약 확인, 상태를 "새 신청 → 연락 완료 → 상담 완료"로 변경
- 등록된 교육과정·행사의 공개/숨김 관리

## 4. 다른 PC에서 설치·배포 순서

1. **Node.js를 설치**합니다 (https://nodejs.org 의 LTS 버전).
2. ZIP 압축을 풀고 그 폴더에서 `npm install`을 실행합니다.
3. `npx wrangler login`으로 **사이트가 올라가 있는 Cloudflare 계정**에 로그인합니다.
4. `npx wrangler d1 create career-bridge-db`를 실행합니다. 출력된 `database_id`를 `wrangler.jsonc`의 `REPLACE_WITH_DATABASE_ID` 자리에 붙여넣습니다.
5. `npm run db:migrate`로 DB 표를 만듭니다. 방문자 수는 기존 값 74부터 이어서 셉니다.
6. `npx wrangler secret list`로 고용24 인증키가 이미 등록되어 있는지 확인합니다.
   - 서버가 `WORK24_API_KEY`, `WORKNET_API_KEY`, `API_KEY` 등 흔히 쓰는 이름을 모두 찾아봅니다.
   - 없으면 `npx wrangler secret put WORK24_API_KEY`로 등록합니다.
7. `npx wrangler secret put ADMIN_PASSWORD`로 센터 관리자 비밀번호를 정합니다.
8. `npm run deploy`로 배포합니다. **배포하면 지금 사이트를 덮어씁니다.**

## 5. 배포 후 꼭 확인할 것

- **고용24 연동**: 지역 코드와 상세 조건 항목 이름은 인증키로 실제 호출해 보지 못했습니다. 지역 버튼(고양·파주·김포)과 "상세 조건 펼치기"가 제대로 나오는지 확인해 주세요.
- **상담 신청 개인정보 문구**: "상담 종료 후 1년 이내 파기"는 임시 문구입니다. 센터 규정에 맞게 바꿔야 합니다. 자동으로 지우는 기능은 아직 없습니다.
- **AI 질문창**: 기존에 쓰던 AI를 알 수 없어서, 별도 키가 필요 없는 Cloudflare Workers AI로 바꿨습니다. 무료 사용량을 넘으면 요금이 생길 수 있습니다.
- **이력서 파일**: 신청자 기기에만 저장되고 센터로 전송되지는 않습니다.
- **"회원가입 필요" 표시**: 설문에서 지적된 사이트 기준입니다. 나머지 사이트는 직접 확인한 뒤 `src/data/links.ts`에서 고칠 수 있습니다.

## 6. 이번에 넣지 않은 요청 (추후 검토)

- 고용24·평생교육포털 **통합 로그인** 연계
- 구직자별 **상담 이력·추천 이유·지원 결과·교육 이력 누적 관리**. 회원 시스템과 개인정보 보호 설계가 필요합니다.
- 상담사가 쓰는 **기관 공용 계정**으로 알선·채용 실적 처리
- 이력서 파일을 센터로 전송하는 기능
